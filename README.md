### 📦 Analytics Service
## 📄 Описание
Analytics Service — микросервис, отвечающий за сбор и агрегацию метрик. Он включает в себя:
- Сбор событий активности пользователей (посты, лайки, платежи).
- Агрегацию статистики по дням и сервисам.
- Предоставление данных для дашбордов.
- Этот сервис потребляет события из Kafka и хранит агрегаты в PostgreSQL.

## ⚙️ Технологии
## Основные технологии
- Java 17: современный язык программирования для создания надежных приложений.
- Spring Boot 3.x: фреймворк для упрощения разработки приложений на Java.
## Базы данных
- PostgreSQL: реляционная база данных для агрегатов и событий.
- Liquibase: инструмент для управления версиями базы данных.
## Взаимодействие между микросервисами
- Kafka: потребление событий из Post Service, User Service, Payment Service.
- OpenFeign: клиент для получения данных из других сервисов.
## Тестирование
JUnit 5, Mockito, Testcontainers.
## Дополнительные инструменты
Lombok, MapStruct, Springdoc OpenAPI, Docker, Slf4j.

## 🔗 Связанные сервисы
- Post Service: события о постах и взаимодействиях.
- User Service: события о регистрации и активности пользователей.
- Payment Service: события о платежах.
- Project Service: события о проектах.
